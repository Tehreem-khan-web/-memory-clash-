# 🧠 Memory Clash

An offline-first memory matching game built with vanilla HTML, CSS, and JavaScript.

## 🎮 Features

- 🧩 Multiple difficulty levels
- 🎨 Multiple icon themes
- ⏱️ Timer and move tracking
- 🔊 Sound effects
- 🏆 Local leaderboard
- 🥇 Achievements
- ⚙️ Settings
- 💾 Local high-score storage
- 📱 Responsive interface
- 🌐 Works offline

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 📖 About the Project

Memory Clash is a browser-based memory matching game designed to combine simple gameplay with a polished interactive interface.

The project was developed using vanilla HTML, CSS, and JavaScript without external frameworks or network dependencies.

## 🚀 How to Run

1. Download or clone this repository.
2. Open `memory-clash.html` in a modern web browser.
3. Choose a difficulty level.
4. Start matching the cards!
