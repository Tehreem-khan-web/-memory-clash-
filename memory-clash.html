About

MEMORY CLASH v1.0

MEMORY CLASH is an offline-first memory matching game. Flip cards, find pairs, and beat your own best score across three difficulty modes and six icon themes.

Built with vanilla HTML, CSS and JavaScript — no frameworks, no external assets, no network required. All progress and high scores are stored locally on this device.
